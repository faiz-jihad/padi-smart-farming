# Frontend Skills

Daftar kemampuan teknis yang relevan untuk Flutter P.A.D.I.

## Flutter

- Widget composition.
- Responsive layout mobile.
- Form validation.
- Loading, error, empty state.
- Theme dan design token.

## State Management

- Riverpod provider/controller.
- Async state handling.
- Dependency injection lewat provider.

## Networking

- Dio client.
- Bearer token auth.
- JSON parsing.
- API exception mapping.

## Routing

- GoRouter.
- Auth redirect.
- Role-based admin route.

## Commands

```bash
flutter pub get
flutter analyze
flutter test
flutter run
```

## Review Checklist

- Tidak ada request HTTP di widget.
- Tidak ada token hardcoded.
- Data real dari API.
- Error API terlihat ke user.
- Non-admin tidak bisa akses admin screen.
- `flutter analyze` lulus.
- `flutter test` lulus.
